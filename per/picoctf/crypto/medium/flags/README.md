# 問題

>Description<br>
>What do the flags mean?

説明<br>
これらの旗は何を意味するのですか？

# 解法要約
国際信号旗、NATO信号旗、勝ち

# 解法

配布ファイルは 1枚の画像ファイル<br>
見たことない画像が並んでいるが `{}` があること、3, 5文字目が同じであるため、それぞれが文字に対応していると予想

調べると国際信号旗という旗のマークらしい<br>
だがいくつか該当しない

さらに調べると NATO信号旗の数字に該当した<br>
ということでフラグゲット

※国際信号旗は国際的に決められ、民間も対象<br>
NATO信号旗は NATO に加盟した国の海軍などが対象<br>
たぶん ctf的にはどうでもいい

※↑追記<br>
ジェム君にこのライトアップ見せたら教えてくれた説が、四角形の旗に合わせたいがため、三角形の国際信号旗の数字ではなく四角形の NATO信号旗にしたとのこと<br>
わりとありそうなので書いておいた
