# 問題

>Description<br>
>In RSA, a small e value can be problematic, but what about N? Can you decrypt this?

説明<br>
RSA暗号では、eの値が小さいと問題になることがあります。では、Nの場合はどうでしょうか？これを解読できますか？

# 解法要約
Nが小さい、yafu、勝ち

# 解法

配布ファイルは txt ファイル 1つ、インスタンスサーバーはなし<br>
txt ファイルの中には N, e, c があった

さて、明らかに N が小さい<br>
数えてみると 81 桁しかなかった

yafu で素因数分解したら rsa で復号して、なぜかリトルエンディアンで入ってるから直してフラグゲット

※因みにこの問題のタイトルの mind your ps and qs はもともと慣用表現として存在しており、p と q は鏡合わせだから気を付けてというとこから、細部に注意を払いなさい、お行儀良くしなさいという意味があるらしい<br>
それを RSA の小さい p, q に注意を払えってとこと書けているっぽい

### 素因数分解のツール

まず、忘れちゃいけないのが factordb<br>
https://factordb.com/index.php<br>
ここには誰かが見つけた素因数分解がいっぱい載っている<br>
だが、常設ctf の場合は問題を作る前に載っていたのか、常設ctf に出されたから載ったのかが分からないため想定解かは怪しい

sympy の factorint は純 python で書かれており、実行速度が遅いため、40-45桁が限界となり今回の問題には適さない<br>
やってみたが、普通にずっと動かなくて悲しかった

ローカルで動かさず、web 上でやってくれる Alpertron というサイトは 70-80桁が限界だそう<br>
https://www.alpertron.com.ar/ECM.HTM<br>
今回の問題に対しては結果 22分かかって素因数分解に成功した

yafu は c 言語ベースのため最適化がされており 85-95桁あたりが限界となる<br>
今回の問題を yafu で解くと大体 2-5分ほどで解けた ( 計ってないから感覚 )

スパコン用アルゴリズムを一般pc で使って放置しても 100-110桁あたりが限界とジェム君は言っていた

因みに現在 2026/06/07 の素因数分解の最高記録は 250桁らしい

恐らくノイマンは 300桁くらい行けるだろうが
